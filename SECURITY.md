# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or leaked credential.
Use the repository's **Security > Advisories > Report a vulnerability** flow:

https://github.com/Jascenn/deployment-scripts-hub/security/advisories/new

Include the affected script, operating system, reproduction steps, impact, and
any suggested mitigation. Remove API keys, passwords, access tokens, private IP
addresses, and server details from logs and screenshots.

Reports are handled on a best-effort basis. Please allow time for validation
and a coordinated fix before public disclosure.
